# reference

Captures from the reference rig (doc 09: Pentium 4 + GeForce 6200 + a
CRT, dual-boot Win98/XP): Direct3D golden frames (`d3d/`), benchmark
results (`benchmarks/`), Wine's Direct3D test baselines (`winetest/`,
`patches/winetest/README.md`), and CRT photo sets and ATAPI traces as they are
taken. Only metadata, traces, photos and results are committed; git
ignores disc dumps and disk images.
