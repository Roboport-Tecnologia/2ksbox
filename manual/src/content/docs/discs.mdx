All your machines share one disc shelf. Add a disc once and any machine
can use it.

## What 2ksbox reads

| Format | Files |
|---|---|
| CUE/BIN | `.cue` with its `.bin` files |
| CloneCD | `.ccd` with its `.img` and `.sub` |
| Alcohol 120% | `.mds` with its `.mdf` |
| ISO | `.iso` |
| A folder | Any folder on your computer, served as a CD |

The drive reads raw dumps the way a real CD-ROM drive does, so CD audio
plays and many copy-protected discs work. A folder becomes an ordinary
data CD, which is handy for patches, drivers and your own files.

## Add discs

Open the **Disc Shelf**, or a machine's **Discs** window, and click
**Add**:

- **Disc image…** picks an image file.
- **Folder as disc…** picks a folder.
- **Guest tools ISO** adds the disc with 2ksbox's drivers.

You can also drag disc images or folders from your file manager onto the
window.

Click the pencil next to a disc to rename it (on macOS, double-click the
name). Enter keeps the new name; Escape leaves the name as it was. The
trash button takes it off the shelf, and leaves the files on your disk
where they are.

## Put a disc in the drive

Open the machine's **Discs** window. The card at the top is the
machine's CD drive. Click **Insert** next to a disc in the library
below. **Eject** empties the drive.

- **Machine turned off:** the disc waits in the drive and the machine
  starts with it.
- **Machine running:** the disc goes into the drive at once, as if you
  had swapped it by hand. Windows sees the change, and AutoPlay runs.

## Swap discs from the machine's window

In the player window, **Machine > Disc** has the same shelf. The disc in the
drive has a check mark. Choose another disc to swap it in, or **Eject**
to empty the drive. As in the **Discs** window, the machine also starts
with that disc next time.

**Insert Disc Image…** and **Insert Folder as Disc…** add a disc to the
shelf and put it in the drive in one step. The Mac App Store version
doesn't have these two: add the disc in the **Discs** window, then
choose it here.

## Swap discs from inside the machine

Games that span several CDs ask for the next disc in the middle of an
install. You can swap from the launcher or the *Disc* menu, or from inside the machine with
the disc shelf tool that the guest tools install:

- On Windows, run `CDSHELF`. With no arguments it opens a window that
  lists the shelf.
- At a command prompt, `CDSHELF` lists the shelf, `CDSHELF 3` inserts
  disc 3, and `CDSHELF E` empties the drive.
- In DOS, `CDSHELF.COM` takes keys: 0 to 9 load a disc, E empties the
  drive, R reads the list again and Esc quits.

<Aside type="tip">
On Windows 98, the guest tools can also put an *MS-DOS mode* shortcut on
the desktop with the CD drive and the Sound Blaster set up, for DOS games
that won't run in a DOS box. Choose it from the `SETUP` menu.
</Aside>

## Install a game

<Steps>

1. Add the game's disc to the shelf.
2. Insert it in a running machine.
3. Install the game the way the box says.
4. Before you play, read [3D games](../3d/) if it's a 3D game.

</Steps>

## Use this computer's own CD or DVD drive

A machine can read real discs in this computer's drive.

**As a second CD drive.** In the machine's **Settings**, on the
**Storage** page, pick the drive in **Optical drive**. The machine gets
a second CD-ROM drive with the real disc in it, next to the usual **CD
in drive**. Windows 95, 98 and XP and DOS find it by themselves. The
picker beside it sets the **speed**: **Automatic** reads as fast as the
drive can (it shows the drive's top speed when the drive reports it),
and a lower speed is quieter and reads scratched discs more reliably.
Press **Refresh** after plugging a drive in or putting a disc in. A
machine whose drive isn't connected refuses to start and says so.

**In the machine's own drive, while it runs.** In the player,
*Machine* > *Disc* lists this computer's drives under your discs, marked
*(real drive)*. Choose one and it goes in the machine's CD drive, as a
disc image would. Choose a disc image or **Eject** to take it out again.
**Look for Drives Again** finds a drive plugged in after the machine
started.

**Changing discs.** When a game asks for the next disc, put it in the
real drive, then choose **Re-read Real Drive** (or **Re-read Second CD
Drive** for the drive on the Storage page) in *Machine* > *Disc*. The
game sees the disc change.

### CD audio and copy protection

2ksbox reads a real disc the way a ripping program does, so CD music,
every track and copy protection work as they do from a disc image. That
needs permission to send the drive commands directly:

- **Windows:** CD audio works as is. Copy-protected discs need 2ksbox
  run as administrator.
- **Linux:** join the `cdrom` group (`sudo usermod -aG cdrom $USER`, then
  sign in again). Without it the machine gets the disc's data only.
- **macOS:** the machine gets the disc's data only.

The Storage page says which you have under **Optical drive**.

<Aside type="caution">
The Flatpak's sandbox has no access to drives until you allow it once:
`flatpak override --user --device=all com._2ksbox.Launcher`.
</Aside>
