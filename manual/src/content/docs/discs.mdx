All your machines share one disc shelf. Add a disc once and any machine
can use it.

## What 2ksbox reads

| Format | Files |
|---|---|
| CUE/BIN | `.cue` with its `.bin` files. The music tracks can also be `.ogg`, `.flac`, `.mp3` or `.wav` files, as in GOG's CD games |
| CloneCD | `.ccd` with its `.img` and `.sub` |
| Alcohol 120% | `.mds` with its `.mdf` |
| ISO | `.iso` |
| A folder | Any folder on your computer, served as a CD |

The drive reads raw dumps the way a real CD-ROM drive does, so CD audio
plays and many copy-protected discs work. A folder becomes an ordinary
data CD, which is handy for patches, drivers and your own files.

## Add discs

Open the **Disc Shelf**, or a machine's **Discs** window, and click
**Add**:

- **Disc image…** picks an image file.
- **Folder as disc…** picks a folder.
- **Game installer…** unpacks a game you downloaded, such as one from
  GOG. See below.
- **Guest tools ISO** adds the disc with 2ksbox's drivers.

You can also drag disc images, folders or game installers from your file
manager onto the window.

Click the pencil next to a disc to rename it (on macOS, double-click the
name). Enter keeps the new name; Escape leaves the name as it was. The
trash button takes it off the shelf, and leaves the files on your disk
where they are.

## Games from GOG

GOG's installers only run on recent versions of Windows, so Windows 98,
XP and DOS can't start them. 2ksbox unpacks them for you instead:

<Steps>

1. In the **Disc Shelf**, click **Add** > **Game installer…** and pick
   the installer (`setup_….exe`). If it came with `.bin` files, keep
   them in the same folder.
2. Wait for the progress bar to finish.
3. The game's files are now on the shelf as a folder disc with the
   game's name. Insert it in a machine and copy the game's folder to
   the hard disk.

</Steps>

2ksbox copies only the game's own files. It leaves out the installer's
extras for modern Windows, such as DirectX and Visual C++ installers.
The files are kept in the `games` folder next to your disc shelf.

<Aside type="caution">
Some GOG releases are built for today's Windows: a 64-bit remaster, or
a game set up to run through DOSBox or a Glide wrapper. Their files
unpack fine, but those parts won't run in an old Windows. The game's
original files are usually there too.
</Aside>

### GOG games with CD music

Many GOG releases of CD games keep the game's CD as a cue sheet
(`game.ins` or a `.cue` file), a `.gog` or `.bin` file and one `.ogg`
file per music track. When you unpack such a game with **Game
installer…**, its CD lands on the shelf too, as *Game name (CD)*: put
that in the drive, and the game plays its CD music from the `.ogg`
files. A cue sheet you have from elsewhere can be added like any disc
image. The music files must be 44.1 kHz, which GOG's are.

## Put a disc in the drive

Open the machine's **Discs** window. The card at the top is the
machine's CD drive. Click **Insert** next to a disc in the library
below. **Eject** empties the drive.

- **Machine turned off:** the disc waits in the drive and the machine
  starts with it.
- **Machine running:** the disc goes into the drive at once, as if you
  had swapped it by hand. Windows sees the change, and AutoPlay runs.

## Swap discs from the machine's window

In the player window, **Machine > Disc** has the same shelf. The disc in the
drive has a check mark. Choose another disc to swap it in, or **Eject**
to empty the drive. As in the **Discs** window, the machine also starts
with that disc next time.

**Insert Disc Image…** and **Insert Folder as Disc…** add a disc to the
shelf and put it in the drive in one step. **Insert Game Installer…**
does the same for a game you downloaded, such as one from GOG: it
unpacks the game onto the shelf and puts its CD in the drive, or the
game's folder when it has no CD. The Mac App Store version doesn't have
these three: add the disc in the **Discs** window, then choose it here.

## Play from your own CD or DVD drive

Your computer's CD or DVD drive can be a second CD drive in a machine,
beside the one the disc shelf fills. In the machine's settings, under
**Storage**, pick it in **Real CD/DVD drive**. Linux only, for now.
**Drive speed** under it sets how fast the drive reads: slower is quieter
and reads scratched discs better.

The machine then has two CD drives: the shelf's, and one with whatever
disc is in your real drive. CD audio plays, and copy-protected originals
see a real disc.

Change discs in the real drive at any time: take one out and put another
in. The machine notices within a second or two, as a real PC would.
Ejecting that drive from inside the machine opens your drive's tray.

<Aside>
On Linux your user needs permission to read the drive (`/dev/sr0`). The
desktop usually gives it to whoever is logged in; if not, add yourself to
the `optical` group.
</Aside>

## Swap discs from inside the machine

Games that span several CDs ask for the next disc in the middle of an
install. You can swap from the launcher or the *Disc* menu, or from inside the machine with
the disc shelf tool that the guest tools install:

- On Windows, run `CDSHELF`. With no arguments it opens a window that
  lists the shelf.
- At a command prompt, `CDSHELF` lists the shelf, `CDSHELF 3` inserts
  disc 3, and `CDSHELF E` empties the drive.
- In DOS, `CDSHELF.COM` takes keys: 0 to 9 load a disc, E empties the
  drive, R reads the list again and Esc quits.

<Aside type="tip">
On Windows 98, the guest tools can also put an *MS-DOS mode* shortcut on
the desktop with the CD drive and the Sound Blaster set up, for DOS games
that won't run in a DOS box. Choose it from the `SETUP` menu.
</Aside>

## Install a game

<Steps>

1. Add the game's disc to the shelf.
2. Insert it in a running machine.
3. Install the game the way the box says.
4. Before you play, read [3D games](../3d/) if it's a 3D game.

</Steps>
